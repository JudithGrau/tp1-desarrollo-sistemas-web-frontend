Proceso del equipo

Bitácora del proyecto

Registro de las decisiones, dificultades y cambios del equipo a lo largo del TP1.

Entrada 1

Organización inicial

Decisión: Decisión: definimos los roles del equipo y la estructura del proyecto. Judith coordina y desarrolla la portada, Matías define el sistema visual, Lucas trabaja el responsive, y Mauro se encarga de la bitácora y el README. Además de su rol específico, cada integrante desarrolla su propio perfil individual.

Acordamos: trabajar sobre un repositorio compartido en GitHub, usar una identidad visual común para todas las páginas y hacer commits progresivos para que quede evidencia del trabajo de cada uno.

Entrada 2

Identidad visual

Decisión: elegimos las tipografías Inter y Sora de Google Fonts y un estilo de tarjetas "double-bezel" para todas las secciones (portada y perfiles).

Motivo: buscamos una estética moderna y consistente, con una navegación tipo "navbar" fija en todas las páginas para que nadie tenga que depender del botón Atrás del navegador.

Entrada 3

Dificultad con el entorno de trabajo

Problema: al clonar el repositorio grupal con GitHub Desktop, apareció el error "Unable to merge unrelated histories" porque se estaba intentando traer el repo del TP1 sobre la carpeta de otro proyecto ya existente.

Solución: se clonó el repositorio correcto (tp1-desarrollo-sistemas-web-frontend) en una carpeta local nueva y vacía, evitando así mezclar historiales de Git de proyectos distintos.

Entrada 4

Avance de perfiles individuales

Cambios: cada integrante desarrolló su propia página de perfil siguiendo el mismo sistema de diseño de la portada (navbar, tarjetas "double-bezel", datos obligatorios de ciudad, edad, habilidades, películas y discos, más una interacción propia en JavaScript).

Próximos pasos: terminar de revisar el diseño responsive en 400px, 900px y 1200px, y completar el README con la documentación final del proyecto y el uso de IA.
