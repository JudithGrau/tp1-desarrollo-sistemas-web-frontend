# TP1 - Desarrollo de Sistemas Web - Frontend

Trabajo Práctico 1 de Desarrollo de Sistemas Web

## Estructura del Proyecto

```
tp1-desarrollo-sistemas-web-frontend/
│
├── index.html              # Página principal
├── integrante1.html        # Página del integrante 1
├── integrante2.html        # Página del integrante 2
├── integrante3.html        # Página del integrante 3
├── integrante4.html        # Página del integrante 4
├── bitacora.html           # Página de bitácora del proyecto
│
├── css/
│   └── style.css           # Estilos del proyecto
│
├── js/
│   └── script.js           # Scripts del proyecto
│
├── img/                    # Carpeta para imágenes
│
└── README.md               # Este archivo
```

## Descripción

Este proyecto contiene las páginas web del Trabajo Práctico 1 de Desarrollo de Sistemas Web.

## Integrantes

- Integrante 1
- Integrante 2
- Integrante 3
- Integrante 4

## Cómo usar

1. Abre `index.html` en tu navegador web
2. Navega entre las diferentes páginas usando los enlaces del menú

## Notas

- Todas las páginas están vinculadas entre sí mediante el menú de navegación
- Los estilos CSS se encuentran en la carpeta `css/`
- Los scripts JavaScript se encuentran en la carpeta `js/`
- Las imágenes deben colocarse en la carpeta `img/`
